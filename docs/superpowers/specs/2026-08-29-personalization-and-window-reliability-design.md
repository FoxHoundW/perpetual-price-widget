# 个性化与窗口可靠性迭代设计

日期：2026-08-29

状态：用户已确认，可开发

## 范围

1. 连接状态灯向窗口中部移动 20px。
2. 392–320px 仅收紧留白，320–300px 才缩小字号；继续缩短市场标签与最新价的紧凑间距，数字不得遮挡。
3. 主体隐藏纵向滚动条和右下角缩放角标，保留滚轮与原生边缘缩放。
4. 主体只保留一层 13px CSS 圆角，关闭原生窗口阴影形成的重叠轮廓。
5. 设置新增“个性化”页面，颜色与透明度立即应用并持久化。
6. 修复设置隐藏后未恢复置顶，并增加 5 秒无焦点置顶重申。

## 个性化参数

- 主体背景色，默认 `#0D131C`。
- 主体背景透明度 `0%–100%`，默认 `99%`。
- 字体透明度 `30%–100%`，默认 `100%`。
- 上涨警示色，默认 `#49E19A`。
- 下跌警示色，默认 `#FF7181`。
- 警示强调透明度 `20%–100%`，默认 `100%`。
- 警示弹框背景色，默认 `#111923`。
- 警示弹框背景透明度 `20%–100%`，默认 `94%`。

所选主体背景色作为底色并保留轻微顶部高光。字体透明度作用于主体行情及侧边警示弹框文字，不影响设置窗口。上涨、下跌颜色作用于主体价格、涨跌幅、警示色条、警示币种名称及对应警示卡强调色。

## 置顶策略

- 设置窗口显示期间暂停主体置顶重申。
- 设置关闭、主体显示、设置保存时立即按设置恢复置顶。
- 始终置顶开启时每 5 秒重新声明一次，但不获取焦点。
- 始终置顶关闭时不执行重申。

## 验证

- 前后端设置默认值、范围归一化、保存与恢复测试。
- 392、340、320、310、300px 布局及长字段测试。
- 主体无可见滚动条和缩放角标，但滚轮与缩放行为保留。
- 设置打开/关闭、托盘显示及 5 秒重申场景不抢焦点。
