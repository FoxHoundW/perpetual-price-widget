# 悬浮窗元素标注图设计

日期：2026-08-29

状态：已确认并生成标注图

## 目标

基于用户提供的悬浮窗截图制作一张 UI 调整参考图。原截图内容、颜色和比例保持不变，只添加红色框线、编号和右侧中文名称图例，方便用户后续准确指出尺寸、比例、位置或间距调整对象。

## 标注方式

- 采用“红框编号 + 右侧图例”的 B 方案。
- 扩展画布右侧区域承载图例，不在行情数字上覆盖长文本。
- 红框使用细线和轻微透明填充；编号使用高对比红底白字圆点。
- 对整体区域和内部元素采用两级框线：整体框较粗，内部元素框较细。
- 引导线仅在编号与元素距离较远时使用，避免画面变成复杂工程图。

## 标注对象

1. 主体窗口外框。
2. 顶部拖动区域。
3. 连接状态指示灯。
4. 行情数据行。
5. 交易对名称。
6. 市场类型标签。
7. 最新成交价。
8. 涨跌方向箭头。
9. 24H 涨跌幅。
10. 行分隔线。
11. 纵向滚动条。
12. 右下角缩放手柄。

重复结构只在第一行完整拆分标注；第二、第三行用一个“行情数据行”整体框说明其重复关系，避免重复框线遮挡界面。

## 输出

- PNG 图片一张，放入项目 `docs/ui-reference/`。
- 图片保持原截图清晰度，并通过右侧扩展画布容纳图例。
- 对话中同时列出编号与元素名称，用户可直接用“调整 7 的字号”等方式提出修改。

## 验收标准

- 12 个编号与图例一一对应。
- 红框不遮挡关键价格数字和交易对文字。
- 原始 UI 不被重绘或改变。
- 在聊天窗口中无需放大即可辨认编号和元素名称。
