# 悬浮窗紧凑布局迭代设计

日期：2026-08-28

状态：待用户书面复核

适用范围：Windows 10/11 主体悬浮窗

## 1. 迭代目标

本次迭代只调整主体悬浮窗的行情视觉与缩放行为，不改变行情来源、刷新周期、异动规则、设置结构和侧边警示。

目标如下：

1. 最新价格不再因行情刷新产生闪烁动画。
2. 最新价格颜色跟随 24H 涨跌方向：正数为绿色，负数为红色，零值使用中性色。
3. 移除主体中的“交易对 / 最新价 / 24H”表头，保留三列数据本身。
4. 窗口缩窄时同步压缩内边距、列间距、交易对内部间距和字号。
5. 价格与 24H 数字始终完整显示，不出现横向滚动条、遮盖或省略号。
6. 达到 300px 宽度后禁止继续缩小。
7. 顶部拖动区域继续可拖动窗口，但鼠标光标始终保持系统普通箭头，不显示抓手或抓取中光标。

## 2. 已确认设计方向

采用视觉稿 C 的紧凑策略：正常宽度保持现有可读性，接近最小宽度时同时缩小间距和字号。

宽度行为：

- 默认宽度保持 392px。
- 可调整区间为 300–2000px。
- 392px 及以上使用当前完整字号和间距。
- 300–392px 之间连续缩放，不使用突变断点。
- Windows 原生窗口和应用设置校验统一使用 300px 最小宽度。

三列优先级：

1. 最新价格列：最小 76px，禁止截断。
2. 24H 涨跌列：最小 57px，禁止截断。
3. 交易对列：使用剩余空间；只有遇到极端长交易对时允许交易对名称显示省略号。

市场标签保留。缩窄时标签字号和水平内边距同步减小，但不会隐藏。

## 3. 价格颜色规则

价格颜色与 24H 涨跌幅使用同一方向：

- `change24h > 0`：价格和 24H 均为上涨绿色。
- `change24h < 0`：价格和 24H 均为下跌红色。
- `change24h = 0`：价格和 24H 均使用中性文本色。
- 陈旧行情继续由整行透明度表达，不改变最后可信方向色。
- 异动警示仍可改变交易对名称、行背景和左侧色条，不覆盖价格的 24H 方向规则。

移除 `price-flash-up`、`price-flash-down` 及对应关键帧。行情更新只替换数字，不触发颜色闪烁或过渡动画。

## 4. 表头与高度

主体不再渲染可见表头。可访问性仍通过每行 `aria-label` 和表格 `aria-label` 提供“交易对、最新价、24H”语义，不保留视觉占位。

高度计算统一改为：

`窗口高度 = 22px 固定框架 + 可视行数 × 44px`

其中固定框架包含 18px 顶部拖动区、底部留白和边框补偿。默认 3 行高度由约 182px 降至约 154px。1–20 行吸附规则保持不变。

Rust 创建/保存窗口、TypeScript 拖动吸附、设置面板当前尺寸说明必须使用同一固定框架常量，避免删除表头后出现空白或吸附偏差。

## 5. 响应式压缩规则

主体使用三列 CSS Grid，不允许内容决定窗口最小宽度。

在 300–392px 区间内连续调整：

- 左右内边距：7–15px。
- 列间距：3–12px。
- 交易对与市场标签间距：3–7px。
- 交易对字号：10–12px。
- 最新价格字号：12–14px。
- 24H 字号：9–11px。
- 市场标签字号：7–8px，并同步缩小标签内边距。

价格和 24H 使用表格数字、右对齐和 `white-space: nowrap`。这两列不得设置 `text-overflow: ellipsis`。主体与页面根节点强制 `overflow-x: hidden`，纵向滚动仅在自选行数超过可视行数时出现。

## 6. 拖动与光标

顶部 18px 区域继续承载 `data-tauri-drag-region`。其 CSS 光标为 `cursor: default`，按下时也不切换为 `grab` 或 `grabbing`。

窗口锁定逻辑不变：

- 未锁定时顶部区域可拖动。
- 锁定窗口后移除拖动能力。
- 无论是否锁定，顶部区域视觉上都保持普通箭头光标。

## 7. 实现边界

涉及组件：

- `src/ui/widget.ts`：价格方向类、移除闪烁类、移除可见表头。
- `src/styles/widget.css`：响应式网格、字号、间距、最小宽度、横向溢出和光标。
- `src/main.ts`：300px 宽度保存下限与无表头高度吸附公式。
- `src-tauri/tauri.conf.json`：原生窗口 `minWidth = 300`，默认高度同步更新。
- `src-tauri/src/models.rs`：窗口宽度校验下限改为 300。
- `src-tauri/src/commands.rs` 与 `src-tauri/src/lib.rs`：窗口高度公式同步更新。
- 前端规范与产品说明书：更新 300px 截图基线、价格颜色与无表头规则。

本次不修改：

- WebSocket 和 REST 行情逻辑。
- 24H 涨跌幅计算。
- 异动提醒状态机和卡片样式。
- 设置面板导航、代理、日志和托盘行为。

## 8. 验证标准

自动测试与静态检查：

1. Widget 渲染测试确认不存在可见表头和 `price-flash-*` 类。
2. 正、负、零 24H 数据分别产生上涨、下跌和中性价格类。
3. 设置宽度归一化测试确认 299px 被校正为 300px，300px 和 392px 保持不变。
4. 1、3、20 行高度计算和拖动吸附使用新的 22px 固定框架。
5. 前端测试、TypeScript 构建、Rust 测试和 Release 构建通过。

视觉与原生验收：

1. 392px、340px、320px、300px 四个宽度下无横向滚动条。
2. BTCUSDT、BTCUSD_PERP、1000000MOGUSDT 等长短交易对下，价格和 24H 数字完整显示。
3. 长交易对空间不足时只截断交易对名称，不遮盖市场标签、价格或 24H。
4. 价格刷新时无颜色闪烁；颜色始终与当前 24H 方向一致。
5. 默认 3 行窗口无表头、无顶部多余空白，高度约 154px。
6. 拖动区域仍能移动窗口，悬停和拖动时均显示普通箭头光标。
7. 将窗口缩至 300px 后无法继续缩小。

## 9. 设计结论

本设计优先保护数字读取：窗口缩窄时先压缩空白和字号，数字列始终完整，交易对名称承担极端情况下的省略。300px 是本轮确认的硬性宽度下限，默认尺寸和正常宽度下的可读性保持不变。
