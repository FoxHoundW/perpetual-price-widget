- 本机已安装 Rust stable-msvc、Microsoft C++ Build Tools 与 Windows SDK，原生开发版和 Release 版均已成功编译运行。
- 前端自动化结果：5 个测试文件、14 项测试通过；TypeScript 类型检查和 Vite 生产构建通过。
- Rust 自动化结果：11 项测试通过，覆盖合约过滤、行情解析、异动冷静期与阶梯基准、设置持久化、日志聚合和脱敏。

- 原生视觉与交互验收已覆盖无边框主体、右键菜单、设置二级导航、交易对管理、异动提醒、日志、隐藏驻留和大小锁定。

## 1. 技术基线

- 桌面框架：Tauri 2。
- 原生与业务层：Rust stable-msvc。
- 界面层：Vite + TypeScript + 原生语义化 HTML/CSS。
- 测试：Vitest（领域与组件）、Playwright（界面与截图）、Rust 单元/集成测试。
- 数据：`settings.json`、`state.db`、`logs.db`、Windows Credential Manager。
- 支持平台：Windows 10、Windows 11，x64 首发。

选择原生 TypeScript 而不是 React，是因为首版只有三个明确界面、组件状态可控，且产品对启动速度、内存和安装体积更敏感。交互复杂度增长到需要路由或大型表格状态时再评估框架迁移。

## 2. 开发阶段

### 阶段 A：工程与产品规范

1. 建立 Vite/TypeScript 与 Tauri 目录。
2. 固化 UI 设计令牌、状态语言、固定列和动效规则。
3. 建立领域类型、默认设置和端口适配层。
4. 完成基础 lint、typecheck、test、build 脚本。

验收：Web 预览可启动，工程可在无 Tauri 环境中独立构建和测试。

### 阶段 B：领域逻辑

1. 合约目录模型与 USDⓈ-M/COIN-M 过滤。
2. 设置校验：可视行数 1–20、刷新 100–2000ms、单币种阈值。
3. 行情快照覆盖式存储与固定容量分钟样本。
4. 多周期异动、四维冷静期、阶梯触发基准、6 小时到期。
5. 重复错误聚合和日志脱敏。

验收：虚拟时间单元测试覆盖边界和状态恢复。

### 阶段 C：三个界面

1. 主体：三列行情、固定布局、陈旧/下架/警示状态、空与错误恢复。
2. 设置：左侧导航，基础设置、双栏交易对管理、异动、代理、日志、关于。
3. 侧卡：同币种 Peek Stack Carousel、点击循环、关闭、自动向内展开、受限滚动。
4. 主体和侧卡共用滚动条、颜色、圆角、阴影和动效令牌。

验收：HTML 预览可交互；100%–200% 缩放下不破版；警示不改变主体列宽。

### 阶段 D：Rust 与 Windows 能力

1. 目录同步、缓存和 24 小时刷新。
2. 双市场 WebSocket、动态订阅、5 秒固定重连、10 秒陈旧检测。
3. SQLite 迁移、裁剪和分页查询。
4. Tauri 命令/事件桥、无边框窗口、拖动缩放、托盘、开机启动。
5. 系统/HTTP/SOCKS5 代理与凭据隔离。

验收：Rust 测试通过；双市场可独立失败与恢复；退出能有序保存。

### 阶段 E：联调和发布

1. 真实公开接口只读冒烟测试。
2. Windows 10/11、多显示器、多 DPI 和任务栏位置验证。
3. 100 个自选、100ms、30 分钟压力测试。
4. NSIS 安装包、MIT 与第三方许可证、README。

验收：满足产品说明书“完成定义”的全部十项。

## 3. 实施顺序与依赖

```text
领域类型/设置 ─┬─> 主体 UI ───────────────┐
               ├─> 设置 UI ───────────────┤
               └─> 异动引擎 -> 侧卡 UI ──┤
目录与行情 Rust ─────────> Tauri 桥接 ─────┼─> 联调/压力/发布
持久化与日志 Rust ───────> Tauri 桥接 ─────┤
窗口/托盘/自启 ────────────────────────────┘
```

领域逻辑不依赖真实网络，界面不直接依赖币安。这样在桌面构建工具缺失时，仍能完成和验证大部分产品行为。

## 4. 当前环境说明

当前开发机已具备 Node.js、pnpm、Rust stable-msvc、Microsoft C++ Build Tools、Windows SDK 与 WebView2。可直接执行 `pnpm tauri dev` 和 `pnpm tauri build`。
