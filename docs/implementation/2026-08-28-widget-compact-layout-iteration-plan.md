# 悬浮窗紧凑布局迭代实施计划

## 1. 渲染语义

1. 移除可见表头，保留表格和行级无障碍描述。
2. 价格颜色改为跟随 24H 的上涨、下跌、中性状态。
3. 移除价格闪烁类和关键帧。
4. 增加组件测试覆盖表头、颜色和闪烁类。

## 2. 响应式布局

1. 主体最小宽度改为 300px。
2. 三列改为数字列硬下限、交易对列弹性布局。
3. 300–392px 连续压缩内边距、间距、字号和市场标签。
4. 禁止主体横向滚动；数字列不省略，交易对名称在极端情况下省略。
5. 顶部拖动区域始终使用普通光标。

## 3. 窗口尺寸同步

1. 原生配置、Rust 设置归一化和 TypeScript 设置归一化统一为 300px 下限。
2. 删除表头后，窗口固定框架高度由 50px 改为 22px。
3. 启动恢复、设置保存、拖动吸附和设置面板尺寸说明统一使用新公式。
4. 默认窗口高度更新为 154px，最小一行高度更新为 66px。

## 4. 规范与验证

1. 更新产品说明书和前端契约中的最小宽度、表头、价格颜色与高度规则。
2. 运行前端测试、TypeScript 构建、Rust 格式检查和 Rust 测试。
3. 生成 HTML/原生窗口视觉验收，覆盖 392/340/320/300px 与长字段。
4. 重新生成 NSIS 安装包并记录哈希。
