# v1.0.0 发布封版计划

## 状态

- 当前阶段：Slice 11 完成，v1.0.0 已正式发布
- 风险等级：低
- 阻塞项：无
- 最后复核：2026-08-31

## 范围与验收标准

### Slice 1：仓库封版

- 版本号统一为 `1.0.0`。
- 应用标识为 `io.github.foxhoundw.perpetual-price-widget`。
- MIT 许可证署名为 `FoxHoundW`。
- 本地构建产物、环境文件和密钥不进入 Git。
- README、变更记录、安全政策与第三方声明反映实际状态。

### Slice 2：自动化验证

- `pnpm test` 通过。
- `pnpm build` 通过。
- `cargo fmt --check` 通过。
- `cargo test` 通过。
- 配置与锁文件不再包含本项目的 `0.1.0`。

### Slice 3：发布产物

- 生成 Windows x64 NSIS 安装包。
- 生成 Windows x64 便携版。
- 重命名为稳定的英文文件名并生成 `SHA256SUMS.txt`。
- 发布目录只作为 GitHub Release 附件，不纳入源码提交。

### Slice 4：行情连接稳定性

- 不再将 10 秒无成交消息误判为 WebSocket 断线。
- 使用主动 Ping/Pong 与市场级连接状态判断真实失联。
- 仅交易对订阅、代理或用户明确要求重连时重建行情连接。
- 真实断线、服务端关闭、心跳超时和读取错误在日志中可区分。

### Slice 5：状态反馈与重新封版

- 低活跃或休市交易对在市场连接正常时保持正常可读，不再因无成交自动半透明。
- 整个市场连接中断时，该市场交易对统一显示断线状态并保留最后价格。
- 前后端全测通过，完成真实多交易对冒烟验证后重新打包 v1.0.0。

### Slice 6：异动历史与触发可靠性

- 历史回补失败后每 5 秒继续重试，不因已有少量实时样本而永久停止回补。
- 分钟样本按启用的最长周期准备，并为 24 小时基线保留足够余量。
- 回补历史与实时样本合并，避免请求期间的新价格被旧历史覆盖。

### Slice 7：周期扩展与连续保存

- 监测周期增加 6h、12h、24h，并与 5min、10min、1h 同时支持多选。
- 多个交易对的涨跌阈值可连续修改、逐项自动保存，切换面板后不回退。
- 长周期在警示卡片中使用小时单位显示。

### Slice 8：回归验证与重新封版

- 通过合成行情验证 5min 至 24h 的触发、冷静期和二次触发。
- 通过真实 Binance K 线验证历史覆盖与接口上限。
- 前后端全测、生产构建和 Windows 发布包重新生成并校验。

### Slice 9：24h 同源判定与限流隔离

- 首次 24h 异动判定直接使用悬浮窗所显示的 Binance 24h 涨跌幅，不因 REST 基线缺失而跳过。
- 同交易对触发后的冷静期和再次提醒继续以上次触发价为基准。
- 单交易对历史回补遭限流时只暂停该交易对，不阻塞其他交易对依次回补。

### Slice 10：侧边警示稳定渲染

- 警示数据没有变化时不替换侧边窗口 DOM，不重复播放入场动画。
- 仅新增警示所在卡片堆播放一次入场动画。
- 点击切换、关闭、到期移除保持即时，不产生整窗闪烁。

### Slice 11：GitHub 正式发布

- 创建公开仓库 `FoxHoundW/perpetual-price-widget` 并推送 `main` 分支。
- 创建 `v1.0.0` 标签与正式 Release。
- 上传 Windows x64 安装版、便携版及 `SHA256SUMS.txt`。
- 回读 GitHub 附件摘要，确认与本地发布文件一致。

## 回归观察项

- 托盘、置顶、鼠标穿透和设置持久化不受封版元数据影响。
- 前端资源和 Rust 二进制能够在 Release 模式中正常打包。
