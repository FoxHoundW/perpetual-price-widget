# 前端设计方向

## 产品认知

- 一句话：常驻桌面、用极少空间显示币安永续价格并提醒显著波动。
- 核心用户：同时工作或浏览、需要余光监控少量合约的桌面用户。
- 核心对象：自选交易对、行情快照、异动警示、连接状态、设置和日志。
- 主体任务：不到一秒读懂交易对、最新成交价和 24h 涨跌幅。
- 成功：用户不需要打开完整交易终端，也不会错过已配置的显著异动。
- 恢复：按 USDⓈ-M / COIN-M 市场连接级别判定断线，保留最后可信价、说明影响并固定重连；无缓存时提供重试和代理设置。

## 产品气质与参考

- 气质：紧凑、安静、可信、轻量；警示时明确但不喧闹。
- 参考：Raycast/Linear 的桌面密度与动效；GitHub Primer 的状态层级；IBM Carbon 的可访问性与诊断模式。
- 借鉴：固定节奏、数字对齐、状态优先、短文案、清晰焦点环。
- 避免：交易所大盘感、霓虹卡片墙、大面积玻璃渐变、营销式标题、无意义图表。

## 视觉令牌

- 字体：`Inter, "Segoe UI Variable", "Segoe UI", sans-serif`；数字启用等宽表格数字。
- 主背景：冷黑蓝，主体高不透明，避免桌面内容影响可读性。
- 表面层级：主体、悬浮、选中三层；只用细边框和克制阴影区分。
- 上涨：绿色；下跌：珊瑚红；中性/连接：青蓝；警告：琥珀色。
- 主体和警示允许用户覆盖背景、上涨、下跌颜色与规定范围内的透明度；设置窗口本身不跟随这些透明度。
- 主体核心文字使用柔和双层深色阴影，在背景完全透明或桌面颜色接近行情色时保持辨识度，不改变字体轮廓粗细；个性化中可在 0–6px 调整，0px 表示关闭。
- 圆角：主体 12px、卡片 10px、控件 7px。
- 间距：4px 基础节奏；常用 8/12/16/20/24px。
- 行高：行情行 44px；三列使用同一网格，警示状态禁止改变列结构。

## 页面与组件

- 主体悬浮窗：唯一高优先级内容是行情列表；状态点固定在角落。
- 单个交易对暂时无成交不等于断线；市场连接仍正常时保持最后价格的正常可读性。
- 主体无视觉表头；缩窄时只收紧留白和列间距，字号保持不变，数字列始终完整。
- 市场标签到价格的最小视觉间距与价格到方向箭头一致。
- 主体滚动条和缩放角标不显示，但滚轮与原生边缘缩放必须保留。
- 鼠标穿透从主体右键菜单开启，并始终可从系统托盘关闭，避免进入不可恢复状态。
- 设置窗口：左侧导航固定宽度，右侧按任务分组；复杂设置不塞进行情表。
- 个性化设置独立成左侧二级页面，颜色采用色板与十六进制输入，透明度采用滑块与百分比。
- 交易对管理：双栏浏览/选择，添加与移除靠近目标行。
- 异动侧卡：每个交易对一个卡堆，不同交易对纵向排列；整卡点击循环。
- 日志：扫描、筛选和复制；技术详情只出现在日志页。

## 动效

- 普通过渡 160ms；卡堆 220ms；尺寸/排序 200ms。
- 只使用 opacity、transform 和可控高度，避免价格列横向移动。
- 最新价格不闪烁，静态颜色跟随 24h 方向；`prefers-reduced-motion: reduce` 时关闭其他非必要位移。

## 截图基线

至少维护：主体默认、主体警示/陈旧、设置基础、交易对管理、异动设置、日志错误聚合、左右侧卡、多卡超高滚动。
