# 前端契约

## 硬性规则

1. 主体只显示交易对、最新成交价、24h 涨跌幅；不显示实现说明。
   主体不渲染字段表头，但必须保留等价的可访问性语义。
2. 警示出现前后三列宽度、位置和窗口宽度必须保持不变。
3. 上涨/下跌不能只靠颜色：同时使用方向文字、正负号、左色条或行底色。
4. 主体隐藏滚动条但保留滚轮；设置与侧卡使用同一可见滚动条令牌。
5. 所有异步区域必须有加载、空、错误和恢复路径。
6. 右键菜单、卡片关闭、日志清空可通过键盘操作；日志清空需要确认。
7. 长交易对、错误消息、代理地址不得撑破布局。
8. 设置窗口最低尺寸下左侧导航和右侧内容仍可操作。
9. 主体背景透明度允许 0%–100%，字体为 30%–100%，警示强调及卡片背景为 20%–100%；边框不跟随主体背景透明度。
10. 始终置顶重申不得获取输入焦点；设置窗口显示期间必须暂停主体置顶重申。
11. 主体字号不得随窗口宽度缩小；空间不足时先收紧留白与列间距，并由最小宽度防止价格和涨跌幅重叠。
12. 鼠标穿透必须提供系统托盘恢复入口，不能只依赖主体窗口右键菜单关闭。
13. 交易对、市场标签、最新价和涨跌幅使用柔和双层阴影增强透明背景可读性；个性化提供 0–6px 阴影大小，0px 关闭；不得使用会改变字宽或造成小字号发糊的粗描边。

## 用户词汇

- 使用：交易对、最新价、24h、异动提醒、上涨阈值、下跌阈值、重新连接、立即同步、已下架、行情中断。
- 仅诊断区使用：WebSocket、REST、SQLite、错误代码、错误指纹。
- 不在主界面出现：ring buffer、snapshot、invoke、payload、contract catalog、cooldown key。

## 状态翻译

| 内部状态 | 用户显示 | 下一步 |
|---|---|---|
| connecting | 正在连接行情 | 自动继续，无需操作 |
| stale | 行情暂时中断 | 保留最后价格并自动重连 |
| reconnecting | 正在重新连接 | 每 5 秒重试 |
| delisted | 已下架 | 进入交易对管理移除 |
| sync_failed_cached | 同步失败，正在使用上次列表 | 检查网络或立即同步 |
| no_catalog | 无法获取交易对 | 重试或打开代理设置 |
| alert_paused | 异动提醒已暂停 | 行情恢复并补齐基线后自动继续 |

连接状态以 USDⓈ-M / COIN-M 市场连接为单位；单个交易对暂时无成交不得单独进入 `stale` 或半透明状态。

## 组件契约

- `TickerRow`：固定三列；数字右对齐；行高固定；状态覆盖不增列。
- `TickerRow`：价格颜色静态跟随 24h 方向；价格和涨跌幅禁止省略，仅交易对名称可在极端长度时省略。
- `AlertStack`：最新卡在顶；`1 / N`；整卡点击循环；关闭只关闭当前展示。
- `AlertStack`：警示数据未变化时禁止替换 DOM；入场动画只用于新增警示，轮询、切换、关闭和到期移除不得重复播放。
- `WidgetScrollbar`：主体视觉隐藏但保留滚轮滚动；缩放角标隐藏但原生边缘缩放保留。
- `AppearanceField`：颜色使用色板＋十六进制值，透明度使用滑块＋百分比，并提供只重置外观的恢复默认操作。
- `SettingsField`：标签、说明、控件、错误四层；错误与字段关联。
- `StatusMessage`：说明发生了什么、影响是什么、下一步是什么。

## 验证清单

- 100%、125%、150%、200% 缩放。
- 300px 主体最小宽度、66px 的 1 行最小高度；全程无横向滚动条。
- 392、340、320、310、300px 下检查字号恒定及市场标签/价格/方向箭头间距。
- 1、3、20 行；0、1、100 个自选。
- 单张、多张同币种、多币种和超高警示。
- 断线、恢复、下架、空列表、首次无缓存。
- 键盘焦点、对比度、减少动态效果。
