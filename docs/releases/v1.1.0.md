# 永续价格悬浮窗 v1.1.0

面向 Windows 10/11 x64，本版本增加可选钱包余额展示，并改善账户明细刷新。

## 更新内容

- 顶部显示账号总余额（折合 USDT），基础设置可开关；读取失败显示 ---。
- 点击账号余额展开各钱包明细，保留顶部拖动功能。
- 总余额和钱包明细由后台统一刷新，默认每秒查询，避免窗口焦点切换影响更新；慢请求不堆叠，限流时遵守服务端退避。
- 主体文字不可选中、使用普通光标，维持简洁布局。
- 不包含仓位浮盈、持仓查询或网页登录功能。

## 下载与升级

- `Perpetual.Price.Widget_1.1.0_x64-setup.exe`：安装版。
- `Perpetual.Price.Widget_1.1.0_x64-portable.exe`：便携版。
- `SHA256SUMS.txt`：文件完整性校验。

升级前请先从托盘退出旧程序。沿用原应用标识，保留已有设置；API 凭据仅保存在本机 Windows 凭据管理器，不随安装包分发。

## 使用与安全

行情不需要密钥。余额功能默认关闭，启用后需自行在基础设置填写账户读取凭据；请勿把密钥发布到 GitHub 或任何公共位置。软件不下单、不转账，不需要提现权限。

账户总额按官方钱包接口返回的各钱包估值汇总，请自行核对官网总览与钱包覆盖范围；不承诺所有账户产品的估值完全一致。网络和接口限流可能使实际更新时间超过一秒。

本程序未进行代码签名，Windows 可能提示未知发布者。与 Binance 无隶属关系，不构成投资建议。
