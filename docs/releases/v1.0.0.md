# 永续价格悬浮窗 v1.0.0

这是永续价格悬浮窗的首个公开稳定版，面向 Windows 10/11 x64。

## 下载选择

- `Perpetual.Price.Widget_1.0.0_x64-setup.exe`：推荐大多数用户使用的安装版。
- `Perpetual.Price.Widget_1.0.0_x64-portable.exe`：无需安装的便携版。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

## 主要特性

- USDⓈ-M 与 COIN-M 永续合约目录、搜索和自选管理。
- 简洁的最新成交价与 24h 涨跌幅悬浮显示。
- 可调刷新周期、多周期异动提醒和同币种警示堆叠。
- 系统托盘、始终置顶、窗口锁定、鼠标穿透和开机自启。
- 背景、字体、阴影和警示外观个性化。
- 网络断线重连、陈旧状态提示、错误聚合日志和代理支持。
- 市场级 WebSocket Ping/Pong 心跳；低活跃交易对不会因短时无成交被误判为断线。

## 安全提示

本版本未使用付费代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本项目的 GitHub Releases 页面下载，并使用附带的 `SHA256SUMS.txt` 校验文件。

## 声明

本软件只读取公开市场数据，不提供交易功能，不构成投资建议，与 Binance 无隶属、授权或背书关系。
